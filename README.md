# AEDs III — Algoritmos e Estruturas de Dados

Repositório destinado ao armazenamento de exercícios, atividades práticas e materiais desenvolvidos durante a disciplina de **Algoritmos e Estruturas de Dados III (AEDs III)**, no curso de Sistemas de Informação.

## 📚 Conteúdo

- **Grafos:** representação e manipulação de grafos.
- **Manipulação de arquivos:** leitura, escrita e armazenamento de dados em arquivos.
- **Algoritmos de menor caminho:** resolução de problemas de caminhos em grafos.
- **Algoritmo de Dijkstra:** busca de caminhos de menor custo em grafos com pesos não negativos.
- Exercícios e atividades práticas desenvolvidos durante as aulas.

## 🛠️ Tecnologias utilizadas

- C++
- Visual Studio Code
- Git e GitHub

## 🎯 Objetivo

Aprofundar os conhecimentos em algoritmos e estruturas de dados, praticando a implementação de grafos, a manipulação de arquivos e a resolução de problemas utilizando algoritmos de caminhos mínimos em C++.
